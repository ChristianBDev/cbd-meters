# cbd-meters

## Dependencies:

`ox_lib` | https://github.com/CommunityOx/ox_lib <br />
`community_bridge` | https://github.com/TheOrderFiveM/community_bridge

## Features:

-   Rob parking meters for cash.
-   Configurable alert chance for police.
-   Configurable robbery duration.
-   Configurable money reward.
-   Configurable cooldown time between robberies.

## Installation:

1. Download the resource from the [GitHub repository](https://github.com/ChristianBDev/cbd-meters)
2. Place the `cbd-meters-main` folder in your server's resources directory.
3. Rename the folder to `cbd-meters`.
4. Add `ensure cbd-meters` to your `server.cfg` file.
5. Ensure you have `ox_lib` and `community_bridge` installed and properly configured in your server, while making sure it starts before `cbd-meters`.
6. Configure the settings in `cbd-meters/config.lua` to suit your server's needs.

## Configuration:

-   Open `cbd-meters/config.lua`.
-   Change configuration settings
